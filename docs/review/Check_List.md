# Integration Check List

Manual verification status for the frontend ↔ user-service / content-service integration.

**Legend**

- ✅ Tested — passing
- ❌ Tested — failing (symptom noted inline)
- ⬜ Not tested yet *(unused for now)*
- 🚧 Not implemented *(unused for now)*

## Home Page
- ✅ Click the Verita icon top left back to home page (from any other page)
- ✅ Click one of the user avatar to the user profile page -> e.g. alexchen
- ✅ Click red heart to like one of the post
- ✅ Click one of the post to see post detail
- ✅ Click the digest card (black background) link up to the digest detail page.
- ✅ See the community digest when not log in, and personal digest when log in.
- ✅ Click the topic under the search bar to filter the post list by the topic
- ✅ See community topic in filter when not log in, and personal filter when log in
- ✅ Click the search bar and type a keyword to see the post list filtered by the keyword
- ✅ Personalized homepage recommendations — recommendation-service ranks the feed from engagement and subscriptions

## Authentication
- ✅ Log in with email `alex@example.com` and password `Password123!` -> seeded user `alexchen` (ADMIN)
- ✅ Sign up with email and password
- ✅ Securely log in — access token in memory only, silent refresh, never in `localStorage`
- ✅ Admin manages user roles and permissions — Admin panel → Users tab (role change + ban)

## User Profile
- ✅ Click the user avatar in the top right to enter the profile page
- ✅ Manage profile information — avatar, bio, display name, organisation, website, research interests
- ✅ Publish a post and see it on the profile page
- ✅ Unpublish a created post — it moves to the drafts list and no longer shows on the profile page after navigating back
- ✅ Open a created post and the editor loads its existing content
- ✅ Publish a draft post — it moves to Posts and the card preview reflects the published content
- ✅ Edit an existing post and save it as draft — the card preview reflects the updated draft content (the editor now sends a freshly derived excerpt on save)
- ✅ Verification badge on verified accounts — shown on profile, post cards, post detail, and comments

## Settings
- ✅ Click the settings icon in the right slide menu to enter the settings page
- ✅ Sign out the current user and see the home page without the user avatar on the top right
- ✅ Turn on/off the show my bookmarks in setting and other users can see the change in the profile page
- ✅ Turn on/off the show my likes in setting and other users can see the change in the profile page

## Content Creation
- ✅ Click the `+ New Post` to enter the post editor page
- ✅ Create a post with a title and Markdown body
- ✅ Select topics from the existing topic list — `TagInput` suggests after one character
- ✅ Insert inline hyperlinks in the body
- ✅ Dedicated source section at the end of a post
- ✅ Real-time Markdown preview beside the editor
- ✅ Explicitly save a post as a draft
- ✅ View and manage drafts and published posts from the profile page
- ✅ Publish a draft / unpublish a published post
- ✅ Edit published posts
- ✅ Delete own posts
- ✅ Insert images via URL or file upload — paste and upload both go to MinIO
- ✅ Upload a cover image

## Post Detail
- ✅ Click the post card to enter the post detail page
- ✅ Comment on posts
- ✅ Reply to a comment — threaded
- ✅ Share button copies the post link
- ✅ Like posts
- ✅ Save and unsave posts to a personal library
- ✅ Like comments
- ✅ Sort comments — Top / Newest / Oldest

## Digest Detail
- ✅ Click the digest card to enter the digest detail page

## AI-Powered Content Intelligence
- ✅ AI summary on a long post on post detail after creating a post
- ✅ Daily AI digest from subscribed topics — generated by a cron job against the past day's content
- ✅ Enter the admin panel to trigger a re-run of failed summaries and re-generate the daily digest from subscribed topics
- ✅ Source attribution on every digest item — each event links back to its originating post or external reference


## Topics
- ✅ Click follow of a topic and see it in the home page topic filter under the search bar
- ✅ Click follow of a topic and refresh the page, then back to the topic page, the topic is still followed


## User Experience
- ✅ Sign in and see "Welcome back, [display name]" in the home page.
- ✅ Sign up a new account and see "Welcome to Verita — your first digest arrives [weekday]".
- ✅ See "Following [topic name]" and "Unfollow [topic name]" in the topic page after following/unfollowing a topic.
- ✅ Try to follow past the cap and see "You can follow up to [N] topics — unfollow one first".
- ✅ There is a undo button after clicking unfollow topic accidentally.
- ✅ See "Settings saved" message after changing settings.
- ✅ Save the profile and see "Profile updated".
- ✅ Bookmark / un-bookmark a post and see "Saved to bookmarks" / "Removed from bookmarks".
- ✅ Share a post and see "Link copied to clipboard".
- ✅ Publish a post and see "Draft published"; unpublish and see "Post moved to Drafts".
- ✅ Delete a post / draft and see "Post deleted" / "Draft deleted".
- ✅ Upload a cover / inline image in the editor and see "Cover image uploaded" / "Image uploaded".
- ✅ Error toasts appear on failed actions (like, publish, unpublish, bookmark, settings save, unfollow all).
