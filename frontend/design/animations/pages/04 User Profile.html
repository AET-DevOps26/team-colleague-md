Tab switch + count badge Production

Profile tabs sit on a 1px hairline (Posts / Bookmarks / Drafts / Likes). Active tab flips text color + 600 weight + 2px accent bottom-border (120ms on color and border-color). The inline .tab-count badge cross-fades its background from --bg-elevated to --accent and its text to white over 120ms. Panel content swaps instantly — production has no slide between panels.

Panel swap is a display: none flip. The only animated parts are the tab text-color, bottom-border, and count-badge background. C06 §3 documents the literals; useTabs() exposes activePanel and a stable switchTab(id).

Manage portal dropdown Production

Per-card overflow menu (Edit / Unpublish / Delete). In production, the dropdown is portaled to document.body to escape the masonry's overflow: hidden and JS-positions to buttonRect.bottom + 6px. Motion is @keyframes dropIn 120ms ease-out — opacity 0→1, translateY(−4px)→0, scale(0.97)→1. Only place in production where popover combines opacity + translate + scale (C07 §3).

Demo positions inline (position: absolute) for clarity; React's useManagePortal() should mirror production's body-portal pattern so the menu can clip past the card boundary. Outside-click / Esc dismiss with no exit animation — matches production exactly.

Card grid stagger Production

On initial panel mount, cards play @keyframes fadeIn (180ms ease-out, opacity + translateY(4px)→0) with a 60ms stagger — same primitive as P02's comment list. Stagger fires only on first-paint of a panel, never on tab re-switch (otherwise toggling tabs would re-trigger the cascade and feel laggy).

Follow toggle Extended

Production's User Profile page renders an Edit Profile button (own-profile view) and has no follow affordance — the only follow toggle in production lives on Digest Management cards (C10 §3, 120ms transition: all). For the public-profile view this page will eventually serve, propose a 200ms accent-color cross-fade on background, color, and border-color: hollow → accent fill on follow, accent fill → hollow on unfollow. Slower than C10's bulk-action 120ms because profile follow is a singular, deliberate action; 120ms feels twitchy when there's only one button on the page.

state: idle

Optimistic update: state flips immediately on click; error path would revert via C04 error toast. No scale, no haptic flash — quiet by design, same rationale as C10 §3.
