§1 Initial mount — hero entry Extended

Production currently mounts content with no entry animation. Proposal: greeting + hero copy fade-up over 360ms on first visit (not on subsequent route returns — store a session flag).

prefers-reduced-motion: collapse all entries to opacity 0 → 1 over 100ms; preserve stagger order so screen readers still announce in sequence.

§2 Topbar shadow on scroll Production

1:1 from pages/Verita Home.html: .topbar::after is a hairline gradient that fades in when .topbar.scrolled applies. Toggle threshold: page scrollY > 4.

TriggerActorMotionNotes
