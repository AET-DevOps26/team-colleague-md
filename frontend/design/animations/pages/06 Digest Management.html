Generate spinner Production

The hero's "Generating…" state shows a single 18px ring spinner with a 2px border (15%-white background, 70%-white top arc) running spin 1s linear infinite. Sourced 1:1 from pages/Verita Digest Management.html:117–118; canonicalized as the production loading vocabulary in C08 §2. This is the only spinner in the production app — it lives on a dark surface, so the rgba whites are baked in rather than tokenized.

Status pill state toggle Production

The Generated ↔ Generating toggle in the hero corner uses a 100ms background + color transition on each pill (pages/Verita Digest Management.html:120). The body swap itself is a display:none class flip — the demo layers an animation: fadeIn 180ms ease-out on the new body so the swap reads as a deliberate state change rather than a flicker. This is the same pattern P02 uses for AI-summary panel reveals.

Click either pill above to see the state toggle. The pill itself uses production's 100ms color swap; the body content cross-fades via fadeIn applied on .show.

Schedule chip toggle Extended

Production has no schedule selector today — the digest is always generated at 06:00 AM. This section proposes a schedule-chip row using C06 §4's 160ms cross-fade contract (background + color + border-color, ease-out). Chips share dimensions across off/on so toggling does not shift the row layout. Multi-select is disabled here (single schedule); the mock enforces it with a click handler.

Pair with useDigestSchedule(); the C06 §4 contract is identical so this surface and Search filter chips share one <TagChip> primitive. Reduced-motion fallback: 120ms linear color/bg only.

Follow toggle Production

The Manage Topics surface uses a 28px .follow-btn with transition: all 120ms covering background, color, and border-color (pages/Verita Digest Management.html:198–200). Idle is hollow with --border-default; followed flips to --accent fill + white text + matching border — no scale, no haptic flash. C10 §3 documents why: bulk-action territory rewards quiet feedback. The label flip (Follow ↔ Following) shares the same 120ms window.
