Post Detail Action Bar

  • The floating .actions-pill at the bottom of the post-detail page — four affordances grouped behind hairline separators
  • Like is the only animated control: 320ms spring bounce on off → on, no animation on off-toggle or count tick

This is the production bar — same markup as the floating pill at the bottom of pages/Verita Post Detail.html, just dropped into a centred stage so you can interact with it. Click each control to see its real behavior.

Comments button jumps to the comments thread in the real page; here it just scrolls the demo. Like-bounce only fires on off → on — toggle off and back on to see it again. Bookmark icon never animates.

Like bounce · off → on only

Trigger
only on liked: false → true · never on toggle-off · never on count tick
Curve
spring cubic-bezier(0.34, 1.56, 0.64, 1) · scale 1 → 1.25 → 0.92 → 1 over 320ms
Cleanup
.bouncing class removed on animationend so re-clicks restart cleanly
Origin
master defined heart fill but no scale; the bounce was previously drafted into C05's feed-card spec, where it isn't reachable in the product. Canonical home is here.

Click the heart repeatedly to confirm the gesture: bounce on off → on, silent unfill on on → off, no flicker on count tick.

"Bump count" demonstrates that count changes alone never trigger the bounce — only the off → on state transition does. This matters for incoming socket updates: another reader liking the post should not animate the local viewer's heart.

Bookmark · color + fill, no animation

Behavior
color → --text-primary · weight → 600 · SVG fill: currentColor · no scale
Why no animation
save is a quieter commitment than like. Master ships it without motion deliberately — adding bounce would draw the eye away from the headline post content.
Idle
outline icon · --text-secondary · weight 500

The bookmark is the master-faithful counterpoint to the like. Click to see the state change without the gesture.

There is no .bouncing equivalent for bookmark. The React <BookmarkButton> should expose saved only — no animation hook, no spring config, no progress.

Share · copy link confirmation

Trigger
click the share button → write the post URL to clipboard → fire toast
Toast
ink pill at bottom-centre (bottom: 90px to clear the bar) · 200ms in/out · 1800ms visible
Variant
this is the post-detail-specific success toast — distinct from the C04 stack and from the welcome pill

Verita's detail page has a single share path: copy link. Other share targets live behind a … overflow menu (out of scope here).

In the real page the toast lives at bottom: 90px so it sits above the floating pill. Here we keep the same offset so the demo reads true; you'll see it appear near the bottom of the viewport.
