§5 — Presence pulse extended · primary

No production source. Adds a 1.6 s breathing ring around the green presence dot to denote "online" without yanking attention. Off-screen on hover and on Reduced-Motion. Toggle a presence state below.

Color

Use case

Pulse is intentionally low-amplitude. If the ring is the only motion on screen, that's the spec — louder pulses break the calm of the feed.

§6 — Notification badge increment extended

When the count changes, the pill briefly scales 1 → 1.32 → 0.94 → 1 over 320ms with cubic-bezier(0.16,1,0.3,1). The number itself crossfades at 100ms. Tap Add 1 repeatedly to see consecutive bumps queue cleanly.

Tempo
pill: 320ms cubic-bezier(0.16,1,0.3,1) · digit: 100ms ease-out opacity+translateY
Trigger
Count delta only — not initial mount, not navigation back to a screen.

If count === 0, the pill should fade out entirely (220ms opacity), not bump. Demo handles the 0 case by hiding the badge node.

§7 — Avatar group / stack fan-out extended

Tight overlap (-8px) at rest; on hover, the stack fans to a 4px gap over 220ms with cubic-bezier(0.22,1,0.36,1). Used in card byline rows ("Read by Elena, Jin, +12") and reaction summaries.

Tempo

The fan-out reveals the count-chip without changing component height. Don't animate the chip itself — it's part of the stack and should travel with the group.

§8 — Reduced-motion fallback extended

One @media (prefers-reduced-motion: reduce) rule at the bottom of the file kills all four extended motions and collapses the production hover lift (§2) to shadow-only — the focus state still has a visual anchor without the 1px translate.

Killed
presence pulse, badge bump, count crossfade, stack fan-out
Reduced
avatar hover: shadow-only (no translateY)
Preserved
follow-button color swap, status-pill color swap (both 120/200ms color, considered safe)

Standard motion

All §5–7 motions active. Toggle Reduced-Motion in your OS to compare against the rule below.

Reduced-motion override (single rule)

@media (prefers-reduced-motion: reduce) {
  .avatar-btn { transition: box-shadow 160ms ease-out; }
  .avatar-btn:hover { transform: none; }
  .av-presence.online .presence-dot::after { animation: none; opacity: 0.5; }
  .bell .count-badge.bumping { animation: none; }
  .bell .count-num { transition: none; }
  .av-stack > .av { transition: none; }
  .av-stack:hover > .av { margin-left: -8px; }
}

Per the C-file convention: one reduced-motion block per file at the bottom. Don't scatter prefers-reduced-motion checks per-keyframe.

React component hints

<Avatar>
Variants: topbar (44/36, hover-lift) · inline (22/26/36, no hover) · profile (80, ringed). Accept tone prop (a/b/c/d) for the gradient family. Initials fallback when no src.
<PresenceDot>
Wraps an <Avatar>. state ∈ idle | online | offline. Pulse only when state === "online"; killed under reduced-motion.
<FollowButton>
Two visual states (idle / followed) with a 120ms all transition. Label switches in-place (Follow ↔ Following); no separate label transition.
<NotificationBadge>
Count delta detection lives in the component. onCountChange(prev, next) triggers .bumping for 320ms then removes the class. Hide entirely at count === 0.
<AvatarStack>
Children clip to max (default 4); overflow renders a +N chip as the last item. Hover fan-out is CSS-only; no JS coupling.
