§1 Token Governance

Production has no canonical focus-ring. Every page falls back to the browser default (auto), which differs across Safari / Firefox / Chrome and inverts unpredictably on dark surfaces. Proposed token below.

TokenValueSourceNotes
--focus-ring 2px solid var(--accent) proposal Width 2px, not 3px — narrow enough that it doesn't visually bleed into adjacent border-radius edges; wide enough to clear AA contrast against --bg-base.
--focus-ring-offset 2px proposal Applied via outline-offset. On rounded primitives (cards, chips), offset doubles as breathing room so the ring never crops the corner.
--focus-ring-glow 0 0 0 3px color-mix(accent 22% transparent) proposal Used on form inputs (existing pattern in C02 Section 1). Composes with the standard outline; do not stack both on the same primitive. 
:root {
  --focus-ring:        2px solid var(--accent);
  --focus-ring-offset: 2px;
  --focus-ring-glow:   0 0 0 3px color-mix(in oklab, var(--accent) 22%, transparent);
}

*:focus-visible {
  outline: var(--focus-ring);
  outline-offset: var(--focus-ring-offset);
}

§2 Per-context focus-visible Normative

Same token, five visual treatments — picked per primitive shape. Tab through the cells below.

Input
border-color → --accent + 3px --focus-ring-glow (matches C02 Section 1).
Button
2px outline, 2px offset (token default).
Link
2px outline, 3px offset, underline color shifts to --accent (signal carries even if outline misses contrast).
Card
border-color → --accent + 2px glow (no outline; ring would clash with card's own border).
Chip
2px outline, 2px offset (same as button — pill primitives share a contract).

§3 Skip link Normative

Every page mounts a skip link as the first focusable element. Hidden until focused; revealed via translateY, never display: none (which removes from tab order).

Resting
transform: translateY(-140%) — fully off-canvas but still in tab order.
Focused
transform: translateY(0) over 200ms cubic-bezier(0.22, 1, 0.36, 1).
Target
Anchored to #main; activating moves keyboard focus and viewport.

§4 Focus trap — modal Normative

Pairs with C03 modal open/close motion. On open, focus moves to the first focusable element inside the modal. Tab wraps within. Esc closes. On close, focus restores to the trigger.

Entry
First input, button, [tabindex]:not([tabindex="-1"]), a[href] inside the modal receives focus 1 frame after the open class lands.
Wrap
Last → first on Tab; first → last on Shift+Tab. Implemented via focusin sentinel.
Exit
Esc close; backdrop click close; explicit close button. All three restore focus to the trigger element.
Reduced
Trap behavior unchanged — focus management is functional, not motion. Only the modal open/close transition shortens.
Tab cycles inside; Shift+Tab also cycles; Esc closes.

§5 Roving tabindex — .actions-pill Normative

Pairs with C12. The pill is a single tab stop — only one button has tabindex="0" at a time, the others are -1. ←/→ moves the active stop and refocuses; Home/End jump to the ends; Tab leaves the group entirely.

§7 Audit checklist Governance

CheckWhat to verify

React mapping

useFocusVisible()
Hook that mirrors :focus-visible behavior in JS for cases where CSS can't reach (Portal'd surfaces). Returns { ref, isFocusVisible }.
<FocusTrap>
Wraps modal/drawer body. Props: active, initialFocus, restoreFocus (defaults true). Implements §4.
<SkipLink>
Mounts at top of every page layout. Props: href (defaults #main), label. Implements §3.
useRovingTabIndex()
Hook for toolbars and segmented controls. Returns { getItemProps(index) }. Implements §5.

Token added to tokens.css when this proposal is approved. All :focus-visible rules across the codebase migrate to outline: var(--focus-ring).
