Hover-delay tooltipExtended · Primary

Need
Sidebar nav rail (P01 Home) and Admin action hints (P08) need tooltips that don't fire on every casual mouse pass. Production §1's instant 100ms is right for editor toolbars, wrong for navigation.
Trigger
mouseenter → setTimeout(400) → add .tip-shown; mouseleave cancels timer + removes class immediately
Motion
Enter: opacity 0 → 1, translateY(4px → 0), 160ms ease-out · Exit: opacity 1 → 0, 80ms — asymmetric on purpose

Asymmetric timing — 400ms in, near-instant out — is the standard for ambient tooltips. Hover and hold to reveal; flick across the row and nothing fires. Try both: a quick swipe across the icons, then settle on one.

Implementation: setTimeout on enter, clearTimeout + immediate hide on leave. Storing the timer per-element handles fast hover-jumps cleanly. The 400ms threshold is what Apple, Material, and Floating UI converged on — short enough to feel responsive when intentional, long enough to ignore casual sweeps.

Edge-arrow tooltipExtended

Need
Anchors near the viewport edge can't always show a tooltip above. The contract: declare placement="top|bottom|left|right", the arrow follows.
Implementation
One .x-tip-edge primitive; placement-specific positioning via parent class. CSS ::after draws the triangle with border.
Motion
Same 160ms ease-out as §4, with the slide direction flipped per placement

Hover each anchor to see its placement. In production, useFloating() would auto-flip when the viewport edge is close — these four are the canonical placements it falls back to.

The ::after triangle uses border-color tricks — no SVG, no separate element. Each placement only paints one of the four border-*-color properties to make the arrow point back at the anchor.

Anchored popoverExtended

Need
Popovers richer than a menu — multi-paragraph hints, mini forms, share targets. Production §3 uses translate + scale on a fixed origin; this proposes setting transform-origin from the anchor edge so the open motion physically reads from the trigger.
Trigger
Click trigger → toggles .open
Motion
opacity 180ms ease-out + scale(0.95 → 1) 180ms cubic-bezier(0.16, 1, 0.3, 1)

The "spring-out" curve cubic-bezier(0.16, 1, 0.3, 1) is gentler than the production linear sort-dropdown — appropriate for richer popovers where the surface itself has visual weight. transform-origin: top left grounds the scale to the trigger's bottom-left corner.

Anchored to trigger

Notice how the open motion appears to expand from the button's lower-left corner — that's transform-origin: top left doing its job. Click the trigger again, click outside, or press Esc to close.

For popovers anchored on the right of the viewport, switch to transform-origin: top right; for ones above, bottom left|right. The four canonical origins map 1:1 to the four placements in §5.

Dismiss governanceExtended

Need
Production §2 and §3 each implement outside-click independently — different selector roots, different stop-propagation rules. The unified contract: every popover dismisses on outside-click, Esc, and scroll-on-ancestor.
Triggers
Esc — global keydown listener
Outside click — document.addEventListener('click', …, true) capture phase
Scroll — scroll on the popover's nearest scroll ancestor

Open the popover, then try each dismissal: scroll the inner area, press Esc, or click any whitespace. The log records what triggered the close.

Capture-phase outside-click avoids the bug where a stop-propagated inner click swallows the dismiss. Scroll-dismiss is essential because anchored popovers don't track scroll — the alternative is repositioning on every frame, which is heavier than just closing.

Reduced motionExtended

Rule
Inside @media (prefers-reduced-motion: reduce): all transform animations collapse, transitions become opacity-only 120ms linear, and @keyframes dropIn disables.
Why opacity stays
Pure on/off makes popovers feel "stuck"; a fade still communicates state change while respecting the user's preference for less motion.

Side-by-side comparison. Click each trigger to compare the full and reduced variants. The reduced cell uses an opacity-only fade; no scale, no translate, no easing curve.

React hint

<Tooltip>
<Tooltip label="Bold · ⌘B" placement="top" delay={400}>. Renders .x-tip primitive (§4). Placement maps to §5. delay={0} recovers the production §1 instant variant for editor toolbars.
<Popover>
<Popover anchor={ref} placement="bottom-start" />. Renders the §6 surface. useDismiss() wires §7's outside-click + Esc + scroll-close. Production §2 and §3 are variant="menu" and variant="portal" respectively.
useFloating()
Wraps anchor measurement, auto-flip, and scroll-tracking. The four placements in §5 are the fallback set when the requested placement collides with the viewport edge.
useDismiss()
Returns { onKeyDown, onOutsideClick, onScroll }. The §7 demo is a hardcoded subset; the real hook also handles focus-loss dismiss for keyboard users.
useReducedMotion()
Returns boolean from matchMedia('(prefers-reduced-motion: reduce)'). The §8 fallback should be CSS-driven (one media query covers everything) — only fall through to JS when geometry changes can't be expressed in CSS.
