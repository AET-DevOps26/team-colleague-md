Toast system — bottom-right

Use
Semantic feedback after a discrete action: success confirmations, recoverable errors, transient warnings, ambient info.
Position
Fixed bottom-right · 22px inset · z-index 60 · stack column (oldest top, newest bottom)
Lifetime
4000ms default · hover pauses · manual × always available
Motion
Enter / exit 220ms · opacity + translateY · same vocabulary across all variants

Variants

Stack & controls

Stack
Newest pushes in at bottom; oldest evicts when count > 2.
Hover
Hover any toast to pause its lifetime timer; leave to resume with remaining time.
Close
× button dismisses immediately, regardless of timer.

Single-fire usage feels like a singleton — most of the time only one toast is visible. The 2-deep stack only kicks in when actions land in the same window.

Welcome pill — top-center

Use
One-shot greeting after successful sign-in · independent of the toast stack
Position
Fixed top-center · 24px from top in production · z-index 80 (one tier above stack at 60)
Lifetime
3000ms · read-once message, no hover-pause needed
Motion
Enter / exit 240ms · --ease-out opacity · --ease-ios translateY -12px→0
Treatment
Tinted neutral fill (--bg-surface + 1px --border-default), text-only at 14.5px / 14px·26px padding — same color vocabulary as the bottom-right stack, but pill shape + top-center anchor + larger size keep the surface distinct without overpowering the page.

Pinned at top:140px in this demo so it doesn't overlap the fixed header bar; in production it sits at top:24px.

React hint

Toast system: showToast({variant, message, lifetime?, action?}) returns toast id; dismiss(id) + dismissAll() for control. Stack capped at 2, hover pauses timer, manual close always available. Files: src/components/Toast.tsx · src/hooks/useToast.ts · stack provider mounted once at app root.

Welcome pill: <WelcomePill message lifetime onDismiss /> · independent component, top-center, tinted neutral fill, text-only at 14.5px, 3000ms. Mounted by the auth flow only — does not share state with the toast stack. Reduced motion follows tokens.css's global override: opacity-only fade at 120ms linear, transforms removed.
