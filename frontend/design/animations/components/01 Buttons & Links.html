Two production variants from Home: .btn-primary (accent fill, dominant action) and .btn-ghost (hairline border, every other action). Hover the buttons to see the tint shift.

120ms is preserved as a literal (not the --dur-fast (180ms) token) for 1:1 fidelity with production. Slowing to 180ms makes the surface feel sticky on rapid hover-passes.

Extended · proposed for <Button> component

Button press · scale 0.97

Down
transform: scale(0.97) over 80ms ease-out on :active
Up
same 80ms transition runs in reverse — symmetric, no spring
Origin
default 50% 50% — visual center matches optical center for these heights

Hold the pointer (or tap and hold on touch) to see the scale. The buttons below carry the .x-press modifier so this section's behavior doesn't bleed into Section 1's production-fidelity samples.

When this lands in production, also retire the standalone .publish-btn in Post Editor — its translateY on hover/active is doing the same job in a non-system way.

Extended · proposed for <Link> component

Text link · underline visible, hover enhances

Idle
1px underline · muted color (--border-strong) · 2px offset — affordance always present
Hover
thickness 1px → 2px · color → currentColor · offset 2px → 3px · 160ms ease-out
Focus
same as hover on :focus-visible — keyboard parity is non-negotiable

Hover or tab through the links — the underline is visible at rest and thickens on interaction. Affordance is never hidden.

React hint

Primary button
<Button variant="primary">Create account</Button> — owns the 120ms hover tint + future 80ms press scale.
Ghost button
<Button variant="ghost">Log in</Button>
Disabled
<Button disabled> — applies the unified opacity: 0.38 contract; component owns the cross-fade so all surfaces converge.
Inline link
<Link href="…">…</Link> — owns the visible-at-rest underline + 160ms hover enhancement (Extended). Use for body copy, never raw <a>.
Icon button
<IconButton aria-label="…" toggle="chevron|fill" /> — exposes the rotate / fill toggle variants (Extended).
FAB
<Fab onSpin={fn} aria-label="…" /> — owns the 600ms spin lifecycle internally; consumer calls fab.spin().
Hook
useButtonInteraction() — returns press / hover / disabled state for custom surfaces (e.g. card CTA arrow in C05).
Reduced motion
useReducedMotion() short-circuits press scale and FAB lift / spin. Hover background tints + underline-thickness changes still run.
