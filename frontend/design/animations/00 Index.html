Verita

Animation Demo Library

A working library of animation prototypes for Verita. Each demo is a small, openable HTML page that specifies one interaction or one page-level choreography in production-faithful HTML/CSS/JS — the source of truth for motion before it lands in React. Components define reusable interaction specs; pages compose them into screen-level choreography.
